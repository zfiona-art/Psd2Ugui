# unity_frame
1. FrameWork: 框架相关: UI、多语言、Network、Message、Platform、Log、存储、加密、Util 相关
2. YooAsset: 资源管理 包括ab资源打包、资源加载等
3. UniTask:  异步编程
4. BestHttp: http请求相关
5. DOTween:  dotween动画库
6. SuperScrollView: 滚动列表支持
7. unitybridge: 跨平台桥接

使用方式: 建议使用 git subtree 添加到项目中 方便开发和管理

```shell
git subtree add --prefix=Assets/Frame ssh://webserver@47.74.179.38:4222/game/unity_frame.git master
```
