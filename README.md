# VectoUI

VectoUI 是一个将 Photoshop PSD 设计稿转换为 Unity UI 资源的工具。它可以导出布局和切图、生成 UI 预制体、按节点名称配置交互组件，并生成 C# 脚本和绑定组件引用。

## 项目文档

| [美术规范](Doc/美术规范.md) | 画布尺寸、画板与图层命名、分组方式、组件节点结构、图片类型、文字要求及交付检查清单 |
| [工具使用说明](Doc/工具使用说明.md) | 工具整体用途、使用前准备、参数设置、各步骤的输入与输出、输出目录、重复导出及验证方式 |

## 使用流程

1. 按照[美术规范](Doc/美术规范.md)准备 PSD 设计稿。
2. 在 Unity 中打开 **Tools → exportRes → psd**，设置源地址和 UI 导出路径。
3. 按顺序执行 **导出结构 → 导出图片 → 导出预制体 → 绑定组件 → 生成脚本**，或点击 **一键导出**。
4. 等待 Unity 编译和自动绑定完成，检查生成结果，并补充业务逻辑。

各步骤的具体处理内容和注意事项见[工具使用说明](Doc/工具使用说明.md)。
